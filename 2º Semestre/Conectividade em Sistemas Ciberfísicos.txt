Tipos de transmição

&#x20;- Multicast -> Um grupo somente recebe, nem todos, nem poucos.

&#x20;- Broadcast -> Todos recebem a mensagem

&#x20;- Unicast -> Apenas os selecionados recebem a mensagem



&#x20;- Todos tem um endereço MAC, que são administrados tanto localmente ou de maneira universal

 - No modelo antigo, o primeiro octedo do endereço ip, determinava a classa e a mascara de rede
 - Prefixo de rede é a parte do endereço ip que identifica a rede

 - Mascara de SUB-REDE --> Serve para separar a parte que identifica a rede da parte que identifica os dispositivos

Para dividir a rede em subredes aplica assim:

11111111. 11111111. 11111111. 10000000
2 subredes 2¹

11111111. 11111111. 11111111. 11000000
4 subredes 2²
E assim em diante


CIDR
 - CIDR é uma mascara de subredes que possibilitou criar redes de tamanho variável, ou seja, sem tamanho inicial
 - O numero depois da barra mostra quantos bits são destinados a rede



 - Endereço de rede -> Quando todos os bits do host estiver em 0
 - Endereço de Broadcast -> Quando todos os bits são 1 ( manda para todos que estão na rede )



 - UMA MASCARA DE REDE A PARTIR DO MOMENTO QUE APARECEU UM 0 NÂO PODE MAIS APARECER 1!!

REGRAS DE ENDEREÇAMENTO

 - Todos os dispositivos na sub-rede devem ter o mesmo identificador de rede (endereço da sub-rede)
 - Cada sub-rede deve ter um identificador de rede (endereço) diferente
 - Quando todos os bits de identificação de dispositivos são 0 temos o endereço de rede
 - Quando todos os bits de identificação de dispositivos são 1 temos o endereço de broadcast da sub rede
